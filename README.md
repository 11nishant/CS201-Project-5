🎬 Movie Recommendation System
This project presents a foundational movie recommendation system developed in C, emphasizing core Data Structures and Algorithms (DSA) principles. It simulates basic recommendation logic without relying on external libraries or machine learning frameworks.​

🛠️ Technologies Used
Language: C​

Data Structures: 2D Arrays, Stacks​
GitHub

Concepts: Matrix operations, user-item preference modeling, stack-based history tracking​

📂 Project Structure
main.c: Contains the core logic for user interaction and recommendation processing.​

genre10.txt, movgen.txt, movuse.txt, names.txt: Data files containing movie genres, movie-user associations, and user names.​

newUser.txt, normalisedRatings.txt: Files for storing new user data and normalized ratings.​

number.txt, r.txt: Auxiliary data files used in processing.​
GitHub

try (2).pdf: Documentation detailing the project's design and implementation.​

⚙️ Features
User-Movie Preference Matrix: Utilizes 2D arrays to represent and process user preferences across various movies.​

Recommendation Logic: Implements a basic algorithm to suggest movies based on user similarity and preference scores.​

History Tracking: Employs stack data structures to manage user navigation history within the recommendation system.​
